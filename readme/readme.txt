Plugin for CudaText
Shows weather in console and status-bar

- "Plugins / Weather / Update"
- "Options / Settings-plugins / Weather / Config"

- Auto-update on start CudaText: 3 hours (cache)
- Auto-city: city is selected automatically by IP
